Desktop-first by design

All of the information on one screen.

Inventory, load visibility, and action appear together so the first desktop glance is immediately useful. It runs offline as a native desktop tool, or in the browser, for teams on the field like in the office.

Automatic and manual placement

Let the engine propose a tight baseline, then drag, rotate, and fine-tune every box by hand.

Inventory anchored to the view

Import all inventory at once, merge multiple files, and edit safely while the 3D load stays in context; No buried modals or spreadsheet juggling.

Snappy and fluent interface

Build on Rust, every interaction is milliseconds-fast. Smart alignment and hints make tight, stable packs pleasant to build.

Low-click, keyboard support and fast workflow

UX designed for speed of use. Customizable key-binds and contextual shortcuts make packing much faster with regular operators.

Live 3D load inspection

Solid or transparent rendering, hover dimensions, and corner markers show exactly what is happening inside the container.

Built around real packing problems

Packing boxes is not all maths; Our software is built rugged. It can allow short overhangs, stacking boxes on mostly flush surfaces and bridging over gaps.

Inventory panel

A clearer way to prepare inventory, for the whole shippment and all in one place.

The planned inventory workspace will bring files, edits, and load progress together. The aim is to replace back-and-forth spreadsheet work with one single view of the shipment.

Live search Import & merge files Safe editing
3D viewport

Place fast, align tight, inspect everything.

Drag and drop boxes manually, snap to near-flush surfaces and container edges, or let the automatic engine build a dense starting point. Visualize the loadout with the layered / transparent view, as well as the box types distribution.
